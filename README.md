## ✨ Features

- **Next.js Frontend Architecture**: Modern App Router, TypeScript, React 19, and Tailwind CSS.
- **Sleek Eye-Friendly Dark UI**: Clean, velvety slate & obsidian aesthetic with subtle accents, zero eye strain, and seamless light/dark mode switching.
- **Interactive Base Domain Switcher**: Clickable domain pill with one-click copy and configurable apex domain.
- **Live Search & Category Filters**: Real-time filtering by category, name, tech stack tags, or description with badge counts.
- **Command Palette (`Ctrl + K` / `⌘K` / `/`)**: Fast keyboard-driven command overlay for quick access and navigation.
- **Subdomain Manager**: Add, edit, or remove subdomains dynamically with `localStorage` persistence.
- **Endpoints Inspector**: Inspect and test documented endpoints and routes per subdomain with cURL commands.
- **JSON Export / Import**: Easily backup and restore domain mapping configurations.
- **View Modes**: Switch between Grid Cards and Compact List/Table layouts.

## 🛠️ Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/aayushrambo8/RedirectingLandingpages.git
   cd RedirectingLandingpages
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local Next.js dev server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Run production server**:
   ```bash
   npm run start
   ```

## ☁️ Deploying to Vercel

1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "Migrate to Next.js frontend with sleek dark UI"
   git push origin main
   ```

2. Import to **[Vercel](https://vercel.com/new)**:
   - Framework Preset: **Next.js** (auto-detected)
   - Click **Deploy**.
